\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}

This report presents a comprehensive smart traffic simulation system developed entirely in Java, focusing on object-oriented programming principles to model complex urban transportation scenarios. The project encompasses a rich map architecture consisting of interconnected nodes, roads, and lanes, populated by diverse vehicle types, each driven by distinct behavioral algorithms. By leveraging fundamental physical kinematics and geometric intersection algorithms, such as Cramer's rule, the simulation accurately represents acceleration, deceleration, lane-changing dynamics, and collision avoidance. The application integrates a robust rendering engine utilizing JavaFX, separating the core mathematical and logical models from the graphical user interface. This structural separation ensures modularity, allowing for real-time visualization of traffic flow, dynamic traffic light coordination, and interactive map editing. The resulting simulation serves as an effective educational tool for evaluating microscopic traffic models and provides a scalable foundation for future enhancements in intelligent transportation systems research.
